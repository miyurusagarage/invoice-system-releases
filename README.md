# Invoice System

Installers for **Invoice System**, an offline desktop app for issuing Sri Lankan VAT tax invoices in the
IRD 2026 format (Gazette 2463/05) and exporting the VAT Schedule 01 for auditors.

## Download

Get the latest version from **[Releases](https://github.com/miyurusagarage/invoice-system-releases/releases/latest)**.

| Windows version | File |
| --- | --- |
| Windows 10 / 11 | `Invoice System_<version>_x64-setup.exe` (recommended) or `Invoice System_<version>_x64_en-US.msi` |

## Installing

Run the downloaded setup file. No internet connection is needed to install or use the app.

The installer is not code-signed yet, so Windows may show **"Windows protected your PC"**.
Choose **More info → Run anyway** to continue.

## Your data

Everything is stored on the computer itself, in `%APPDATA%\com.invoicesystem.desktop\`.
A copy is made automatically each day, and you can save a backup to a USB drive from
**Settings → Data & backups**.
